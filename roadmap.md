### Driver Portability (Fallback)
- **Downgrade to LHM 0.9.4 (WinRing0) for truly portable driver loading** — LHM v0.9.4 (Nov 24, 2024) is the last version using WinRing0, a non-PnP kernel driver that creates its device directly in `DriverEntry`. This allows loading via the Service Control Manager (`sc create` + `sc start`) — no installer, no PnP device node, no DriverStore staging. WinRing0.sys is embedded in the DLL as a GZip-compressed .NET resource and self-installs inside `Computer.Open()`. This would eliminate `lhm_process.py` entirely (the PawnIO installer download/run/uninstall flow). **Trade-offs:** (1) WinRing0 is signed with an expired certificate — may fail to load on systems with Secure Boot enabled (PawnIO is WHQL-signed and works everywhere); (2) loses DIMM temperature, NVMe thermal sensor 1, and NVIDIA GPU core voltage sensors added in v0.9.5/v0.9.6; (3) LHM 0.9.4 DLL targets .NET Framework 4.7.2 (not .NET 10). Download: `https://github.com/LibreHardwareMonitor/LibreHardwareMonitor/releases/download/v0.9.4/LibreHardwareMonitor-net472.zip`. Investigation confirmed v0.9.0–v0.9.4 all use WinRing0; PawnIO was introduced in commit `eb5e1a2` (Sep 16, 2025) and first released in v0.9.5 (Jan 7, 2026). Keep as fallback if PawnIO installer approach proves problematic for users.
